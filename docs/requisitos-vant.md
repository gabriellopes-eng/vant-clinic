# Requisitos do Projeto VANT

## Visão geral

O VANT é um sistema para clínicas de estética, salões de beleza e profissionais autônomos. O sistema busca organizar a rotina de atendimentos, reduzir conflitos de agenda e melhorar a eficiência operacional.

## Problema

Muitos estabelecimentos de estética sofrem com conflitos de agendamentos diariamente. Isso afeta o desempenho da equipe, a receita e a qualidade do serviço prestado.

## Objetivos

- Centralizar a agenda.
- Prevenir overbooking.
- Controlar pagamentos.
- Melhorar a eficiência operacional.

## Tecnologias

- Python
- Django
- SQLite
- Git
- GitHub

## Requisitos funcionais

RF01: O sistema deve permitir o cadastro de clientes.

RF02: O sistema deve permitir o cadastro de profissionais de estética.

RF03: O sistema deve permitir o cadastro de serviços estéticos.

RF04: O sistema deve permitir a criação de agendamentos.

RF05: O sistema deve impedir dois agendamentos no mesmo horário para o mesmo profissional.

RF06: O sistema deve permitir a consulta da agenda.

RF07: O sistema deve permitir o reagendamento.

RF08: O sistema deve permitir o cancelamento de agendamentos.

RF09: O sistema deve permitir o registro do status de pagamento.

RF10: O sistema deve permitir relatórios simples.

## Requisitos não funcionais

RNF01: O sistema deve ser desenvolvido em Python com Django.

RNF02: O sistema deve utilizar SQLite inicialmente.

RNF03: O sistema deve possuir login e senha.

RNF04: O sistema deve ter organização simples e fácil de manter.

RNF05: O código deve ser versionado com Git e GitHub.
